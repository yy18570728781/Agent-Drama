## 它能帮你解决什么问题

传统的 AI 视频制作通常要在文档、生图工具、视频工具、网盘和剪辑软件之间来回切换。Agent Drama 更像一个 AI 漫剧片场：你可以把故事、角色、场景、参考图、视频片段和生成任务放到一张画布上，用连线表达它们之间的引用关系。

常见使用场景包括：

- 把小说、大纲或短剧文案拆成可制作的分镜。
- 为同一个故事统一管理角色、场景、道具和镜头素材。
- 接入本地 ComfyUI 或本地大模型，用自己的显卡算力完成图片和工作流生成。
- 根据角色图、场景图、首帧、尾帧或音频生成视频片段。
- 把多个镜头按顺序合成为短剧片段或漫剧视频。
- 复用已有画布项目，继续扩写、补镜头和批量生成。
- 通过豆包、Codex 或 MCP 工作流，让 AI 助手协助整理素材和准备生成任务。

## 主要能力

### 剧本到分镜

导入小说、故事大纲、短剧文案或已有剧本后，可以继续整理角色、场景、镜头和提示词，让文字内容变成可制作的分镜流程。

### 无限画布创作

在画布里放置文本、图片、视频、音频、角色、场景和生成节点。节点之间可以连线，表示参考图、首帧、尾帧、音频和上游素材如何被下游任务使用。

### 本地部署与本地显卡算力

桌面端支持本地 ComfyUI 接入，也支持围绕本地模型和本地显卡构建生成流程。你可以优先使用自己的电脑算力，减少对云端积分和第三方平台的依赖；也可以在同一个项目里同时使用本地能力和云端模型。

### 图片与视频生成

支持图片生成、图生视频、参考生视频和多模态参考。你可以围绕角色定妆、场景搭建、分镜图、连续镜头和短剧片段进行制作；本地 ComfyUI 工作流和云端模型可以按实际项目成本、速度和质量灵活选择。

### 镜头合成与剪辑

多个视频镜头可以按画布引用顺序进入剪辑流程，用来快速预览、拼接和导出短片。

### AI 助手连接

支持豆包连接、Codex / MCP 连接等工作流。AI 助手可以读取画布内容、整理节点、导入素材、写入剧本和准备生成任务，让重复制作步骤更容易自动化。

### 公开画布参考

可以查看或发布公开画布案例，学习别人如何组织故事、素材、提示词和生成链路，也可以复制案例继续编辑。

## 基础使用流程

1. 打开下载地址，安装 Agent Drama 桌面端。
2. 登录后进入工作台，新建项目或打开已有项目。
3. 导入小说、剧本、图片、视频或音频素材。
4. 在画布里整理角色、场景、分镜和生成节点。
5. 如果你有本地显卡或 ComfyUI，可以先配置本地生成环境。
6. 用连线把参考图、首帧、尾帧、音频等素材连接到生成任务。
7. 生成图片或视频，结果会自动回到画布中继续使用。
8. 需要成片时，把多个视频镜头加入剪辑流程并导出。

### 支持哪些 AI 模型？

Agent Drama 支持多种文本、图片、视频和音频模型，具体可在桌面端的模型供应商、模型模板和生成配置中查看。
