# Agent-Drama｜Agent Drama AIGC｜AI短剧与漫剧创作工具

**Agent-Drama（Agent Drama AIGC）** 是一个面向抖音短剧、AI 漫剧、小说改编和 AIGC 视频创作者的本地桌面工作台。它不是单一的生图工具，而是把 **Home 创作入口、无限画布、剧本拆分、角色场景素材、图片生成、视频生成、连线剪辑、豆包连接、Codex/MCP 连接和公开画布分享** 放到同一个创作流程里。

## 你可以用它做什么

### 1. Home UI：从首页进入创作工作台

Agent Drama 的 Home UI 是创作入口，不只是普通后台首页。

- 可以从首页进入项目、画布、素材、任务记录和模型配置。
- 可以查看最近项目、继续创作、打开创作广场和公开画布作品。
- 支持桌面端和网页端入口，适合新手从首页一步步进入制作流程。
- 首页会展示产品入口、教程、会员/积分状态、任务反馈和常用功能按钮。

### 2. 无限画布：把剧本、素材和生成流程放在一张画布里

Agent Drama 的核心是 AI 漫剧无限画布。

- 在同一张画布里放文本、剧本、角色、场景、图片、视频、音频和生成节点。
- 支持拖拽、缩放、节点整理、素材管理和连线引用。
- 连线表示真实引用关系：上游角色图、场景图、首帧、尾帧、音频等可以直接作为下游生成参考。
- 生成结果会回填到画布节点，方便继续连线生成下一镜。
- 支持本地缓存、云端同步、项目恢复和素材库管理。

### 3. 小说 / 短剧改编

- 把小说、故事大纲、短剧文案拆成可制作的分镜。
- 管理角色、场景、道具、镜头、提示词和视频提示词。
- 适合做 AI 漫剧、抖音短剧、小说改编视频、故事板和连续镜头制作。

### 4. 图片与视频生成

- 支持多模型图片生成、图生视频、参考生视频和多模态参考。
- 可把角色图、场景图、首帧、尾帧、音频等作为生成参考。
- 支持模型供应商、模型模板、尺寸、比例、时长、清晰度等配置。
- 适合做角色定妆、场景图、分镜图、短剧镜头和连续视频片段。

### 5. 连线剪辑 / 智能剪辑

- 画布里的多个视频可以加入剪辑节点。
- 支持按参考顺序合成视频，适合快速把多个镜头拼成成片。
- 支持打开完整剪辑工作台，进行裁剪、预览和导出。

### 6. 豆包连接：让豆包控制本地画布

Agent Drama 提供豆包桌面连接能力，让豆包可以通过本地 MCP 连接器操作画布。

- 在桌面端设置里复制豆包 HTTP 连接信息。
- 在豆包「技能 · 连接器 · 伙伴」里新建自定义连接器。
- 连接后可以让豆包读取画布、整理节点、写入剧本、导入素材、准备生成任务。
- 连接器只连接本机桌面端，不需要把本地文件直接暴露到公网。

### 7. Codex / MCP 连接：让 AI 助手参与制作

Agent Drama 支持 Codex / MCP 插件连接，把桌面画布变成 AI 助手可以调用的创作工具。

- AI 助手可以读取当前画布、节点、连线和任务状态。
- 可以把小说改编结果保存成文档节点。
- 可以导入图片、准备图片/视频生成节点、提交生成任务并回填结果。
- 适合让 AI 助手参与拆分镜、整理素材、批量创建节点和检查制作进度。

### 8. 公开画布与创作广场

Agent Drama 支持把画布作品发布为公开案例，方便别人学习和复制流程。

- 可以把画布发布到首页创作广场。
- 支持封面、演示视频、名称、说明、分类和标签。
- 公开画布可以查看节点、连线、提示词和制作流程。
- 登录后可以复制公开画布到自己的项目里继续编辑。

## 基础使用流程

1. 打开下载地址，安装 Agent Drama 桌面端。
2. 登录工作台，从 Home UI 进入项目或智能画布。
3. 新建项目，导入小说、剧本、图片、视频或音频素材。
4. 在无限画布里创建文本、角色、场景、图片生成和视频生成节点。
5. 用连线把上游素材连接到下游生成节点。
6. 生成图片或视频，结果会回填到画布。
7. 需要成片时，添加连线剪辑 / 智能剪辑节点，把多个视频合成。
8. 需要 AI 助手协作时，连接豆包、Codex 或其他支持 MCP 的工具。

## 常见问题

### 这是开源代码仓库吗？

这个仓库主要用于品牌搜索、下载入口和产品说明，不包含 Agent Drama 的业务源码。

### 为什么 GitHub / Gitee 上只有文档？

因为这个仓库的目标是让用户能通过搜索引擎找到 **Agent Drama**，并快速进入下载和使用说明。产品代码和服务配置不放在这里。

### 豆包连接和 Codex 连接有什么区别？

豆包连接面向豆包桌面端的自定义连接器；Codex / MCP 连接面向支持 MCP 的 AI 助手。两者都可以连接本地桌面画布，但安装方式不同。

### 支持哪些模型？

Agent Drama 支持多种图片、视频、文本和音频模型。具体可在桌面端的模型配置、模型供应商和模型模板里查看。
