# agent-drama｜Agent Drama AIGC｜AI 漫剧片场与短剧创作工具

**agent-drama（Agent Drama AIGC）** 是一个面向短剧、漫剧、AI 视频创作者的本地桌面工作台。它把剧本、角色、场景、分镜、图片生成、视频生成、智能剪辑和素材管理放到同一个画布里，适合做抖音短剧、AI 漫剧、小说改编视频、分镜生图和参考生视频。

## 主要功能

### 1. AI 漫剧画布

- 在无限画布里整理剧本、角色、场景、图片、视频和音频素材。
- 支持节点连线，把上游素材作为下游生成参考。
- 支持项目保存、本地缓存、云端同步和素材库管理。

### 2. 小说 / 短剧改编

- 把小说、故事大纲或短剧文案拆成可制作的分镜。
- 支持角色、场景、道具、镜头、提示词和视频提示词管理。
- 适合做 AI 漫剧、短剧分镜、故事板和连续镜头制作。

### 3. 图片与视频生成

- 支持多模型图片生成、图生视频、参考生视频和多模态参考。
- 可把角色图、场景图、首帧、尾帧、音频等作为生成参考。
- 支持多供应商模型配置，方便接入不同 AI 平台。

### 4. 连线剪辑 / 智能剪辑

- 画布里的多个视频可以直接加入剪辑节点。
- 支持按参考顺序合成视频，适合快速把多个镜头拼成成片。
- 支持打开完整剪辑工作台，进行裁剪、字幕、转场和预览。

### 5. 本地桌面端与 MCP 插件

- 桌面端支持本地配置、本地任务队列和本地素材缓存。
- 支持 MCP / Codex 插件，把画布能力连接到 AI 助手工作流。
- 可用于自动化整理素材、生成分镜、写入画布节点和检查制作进度。
